ABOUT SECURITY TOOLS

What Can You Do With These Security Tools?

PDF documents are often used for reports, applications, business documents and files that need to be shared in a consistent format. In some situations, you may also need to protect a PDF, remove protection from a file you are authorized to access, or add a visible watermark.

ConvertNova provides separate browser-based tools for common PDF security tasks. You can protect supported PDF documents with a password, unlock supported documents when you have the necessary permission, or add text and image watermarks.

Keeping each operation as a separate tool makes it easier to select the exact PDF security task you need without searching through unrelated document tools.

SECURITY TIPS

Tips for Working With Protected PDFs

A few simple practices can help you work more safely and effectively with PDF documents.

Use Protection Appropriately

Protect documents when access control is appropriate for the information they contain.

Keep Passwords Secure

Use a password you can securely manage and avoid sharing document passwords unnecessarily.

Unlock Only Authorized Files

Only remove protection from documents when you have the necessary permission to access or modify them.

Review Watermarks

Check the watermark position, readability and appearance before sharing the final PDF.
